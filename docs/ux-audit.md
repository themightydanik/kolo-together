# UX-аудит — Product Experience, PR #9

База: `main` после PR #8 (`35983af`). Метод: чтение маршрутов и состояний, осмотр локального демо в Chromium, затем проверки реального локального Supabase двумя новыми аккаунтами. Это экспертная оценка: правило «понятно за 3 секунды» — критерий композиции, не измеренный результат исследования пользователей.

## Ежедневные и редкие действия

Ежедневно: выбрать следующий шаг, отметить собственное участие, ответить/пропустить карту. Реже: изменить условия, отозвать публикацию, закрыть игру, выйти из пары. Эти действия остаются доступны через подписанное меню и подтверждение, а не исчезают. Создание не становится обязательным, когда человеку нечего выполнять.

Партнёры имеют одинаковые права; интерфейс не ставит одного в роль управляющего. Ожидание второго — нейтральный статус. Никаких рейтингов, штрафов или обязательных серий. Демоданные показывают содержание и навигацию, не симулируют успешную запись или покупку.

## Ограничения оценки

Automated Axe + keyboard/focus checks не заменяют испытание живым пользователем со screen reader. WebKit Linux проверяет движок и изображения, но не физический iPhone/Safari. Эмоциональная ценность, скорость понимания и желание вернуться требуют пользовательского исследования; метрики улучшения не заявляются.

## Результаты проверки этой реализации

- `npm run typecheck`, `npm run lint`, `npm run build`: успешно. Vite предупреждает об основном JS chunk >500kB (973kB / 274kB gzip); lazy-loading остаётся следующим улучшением, лимит не замаскирован настройкой warning.
- `npm test`: 146 UI/unit + 126 PostgreSQL security/RPC + 6 полнофайловых migration/backfill тестов; все проходят. Catalog checker сверяет обе версии и SQL.
- `npm run test:browser`: 12/12, Chromium и настоящий Playwright WebKit Linux. Pixel snapshots обеих сторон просмотрены визуально; четыре ширины, обе темы, reduced motion, клавиатура/фокус, readonly demo rituals, Axe A/AA.
- Настоящий локальный Supabase: Auth/email/PKCE/recovery, PostgREST JWT/RLS/RPC, задания/цели/магазин/ритуалы/статистика/близость и сохранность балансов — smoke успешно. Это минимальный локальный стек PostgreSQL/Auth/PostgREST/Kong/Mailpit; Storage/Realtime/Edge services не запускались, эти интерфейсы их не используют.
- Два новых локальных Auth-аккаунта в изолированных Chromium: все пять вкладок, приглашение, одна общая карта, видимый receipt, приватный сохранённый черновик, слепая публикация, пропуск, конкурентный next, потеря sessionStorage/reload, закрытие и leave — успешно. Только эти собственные временные аккаунты удалены после проверки.
- Особенность sandbox: отсутствующие WebKit shared libraries распакованы в `/tmp` из Debian-пакетов и доступны самому движку. Для запуска использован `PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1` (обход обнаружения системных пакетов, не пропуск теста); WebKit действительно запускался и делал снимки. В обычной среде используйте `playwright install --with-deps webkit`.

Удалённые миграции, production deploy и merge не выполнялись. Проверки не являются реальным исследованием retention или ручным тестированием физического screen reader/iOS.
